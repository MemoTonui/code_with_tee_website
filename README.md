# CodeWithTee — Former Illustration Style

This is the redesigned CodeWithTee homepage based on the earlier colourful educational website direction.

## Stack

- Next.js 14
- React
- TypeScript
- Tailwind CSS
- Poppins
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Then visit:

```text
http://localhost:3000
```

## Homepage flow

1. Hero — where curious minds learn to create with code
2. What is CodeWithTee?
3. Explore, Create, Build — six learning areas
4. What could you build?
5. Growing with CodeWithTee — age groups 6–18
6. The CodeWithTee journey — Imagine → Explore → Build → Get stuck → Improve → Create again
7. Why it matters — the skills children develop
8. Behind CodeWithTee
9. Final contact/footer
